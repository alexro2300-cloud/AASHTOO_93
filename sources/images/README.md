# Guía de nombres de imágenes (UI)

Coloca tus imágenes en esta carpeta (`sources/images/`) con **exactamente** estos nombres.
El sistema las carga automáticamente según la zona indicada.

## Encabezado
- `logo_school.png` → Logo escolar (arriba, lado izquierdo).
- `logo_lab.png` → Logo del laboratorio (arriba, junto al logo escolar).

## Pestaña Tránsito / ESALs
- `traffic_types.png` → Imagen representativa de tipos de vehículos (debajo de la tabla de clasificación).

## Ayudas visuales por parámetro

### Tránsito / ESALs
- `help_aadt.png` → Ayuda de **TPDA total**.
- `help_dd.png` → Ayuda de **DD**.
- `help_dl.png` → Ayuda de **DL**.
- `help_growth.png` → Ayuda de **Crecimiento anual**.

### Parámetros AASHTO
- `help_rel.png` → Ayuda de **Confiabilidad R**.
- `help_so.png` → Ayuda de **So**.
- `help_pi.png` → Ayuda de **Pi**.
- `help_pt.png` → Ayuda de **Pt**.
- `help_mr.png` → Ayuda de **Mr (subrasante)**.

### Capas / Espesores
- `help_a1.png` → Ayuda de **a1**.
- `help_a2.png` → Ayuda de **a2**.
- `help_a3.png` → Ayuda de **a3**.
- `help_m2.png` → Ayuda de **m2**.
- `help_m3.png` → Ayuda de **m3**.
- `help_sn1.png` → Ayuda de **SN1 objetivo**.
- `help_sn2.png` → Ayuda de **SN2 objetivo**.
- `help_sn3.png` → Ayuda de **SN3 objetivo**.

### Costos preliminares
- `help_width.png` → Ayuda de **Ancho de corona**.
- `help_cost_d1.png` → Ayuda de **Costo carpeta**.
- `help_cost_d2.png` → Ayuda de **Costo base**.
- `help_cost_d3.png` → Ayuda de **Costo subbase**.

## Recomendaciones
- Formato sugerido: **PNG**.
- Si una imagen no existe, la app mostrará un mensaje indicando la ruta esperada.
